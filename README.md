# 拼豆定位器

手机优先的拼豆图纸辅助工具。

## 已实现

- 原生手机相册文件选择：不再用隐藏 input + JavaScript `.click()` 的方式打开相册。
- 独立“选择照片 / 拍照 / 粘贴 / 拖拽”入口。
- 支持横图旋转。
- 自动估算网格，并允许手动输入 19×19、20×20、67×67 等尺寸。
- 手动微调裁切，处理不同网站导出的边框、标题、水印和留白。
- Tesseract.js 浏览器 OCR 读取格内编号，例如 H5、D12、A22、C14、F4。
- OCR 漏读时，根据已识别编号对应的底色补全相同颜色。
- 重新绘制工作网格，并固定每 5 格一条粗线，对应实体 5×5 模块。
- 点颜色编号后只突出该颜色。
- 点格子标记完成；显示总坐标、5×5 模块编号、模块内坐标。
- OCR 单格读错时可手动修正。
- PWA 外壳，可部署后添加到手机主屏幕。

## 使用建议

1. 用 Safari / Chrome 打开部署后的 HTTPS 网站。
2. 直接点“选择照片”。
3. 对照原图顶部和侧边数字确认行列数。
4. 如果红色裁切框没有只罩住网格区域，展开“手动微调裁切”。
5. 点“识别格内颜色编号”。
6. 选一个颜色编号开始拼。

所有图片处理与 OCR 都在浏览器本地完成，不上传到服务器。
